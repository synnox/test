Propriété intellectuelle

Les affiches de films et séries affichées sur ce site proviennent de TMDb (The Movie Database) et sont soumises à leur propre licence. TMDb est une base de données ouverte et communautaire ; les droits d'auteur des images appartiennent à leurs propriétaires respectifs.

Le code source de ce site est fourni à titre éducatif et de démonstration.

Données personnelles

Sn Streaming ne collecte aucune donnée personnelle. Le site utilise localStorage dans votre navigateur pour enregistrer votre historique de lecture (clé : sn_history). Ces données restent entièrement dans votre navigateur et ne sont jamais transmises à un serveur.

Aucun cookie tiers, aucun tracker, aucun analytics n'est utilisé sur ce site.
